## Инструкция по запуску проекта

### Запустить docker-compose

```bash
make up
```

### Остановить контейнеры

```bash
make stop
```

### Остановить и удалить контейнеры

```bash
make down
```

### Проект
демонстрационный сервис с простейшим интерфейсом, отображающий данные о заказе.

Что сделано:

- Развернуто локально PostgreSQL

- - Создано свое БД
- - Настроен свой пользователь
- - Созданы таблицы для хранения полученных данных

- Разработан сервис

- - Реализовано подключение к брокерам и подписка на топик orders в Kafka
- - Полученные данные записываются в БД
- - Реализовано кэширование полученных данных в сервисе (in memory)
- - В случае прекращения работы сервиса восстанавливается кэш из БД
- - Выдаваются данные по id из кэша
- Разработан простейший интерфейс отображения полученных данных по id заказа

- Сервис покрыт автотестами
- Логи в JSON-формате
- WRK и Vegeta
